# LifeHackOrMyth_Dladla

The LifeHackOrMyth project is an Android mobile application developed to help users distinguish between commonly shared life hacks and widely believed myths. The main purpose of the application is to promote critical thinking and general awareness by presenting users with a series of statements and requiring them to decide whether each statement is factual or misleading. In an age where information is rapidly shared across social media and other platforms, many individuals accept claims without verification. This application addresses that issue by providing an interactive and educational tool that challenges users to think more carefully about the information they encounter in everyday life.

The application was developed using Kotlin in Android Studio, with XML used to design the user interface. It consists of multiple activities, including a main welcome screen and a quiz screen. The main screen introduces the user to the application and includes a start button that navigates to the quiz section using Android intents. The quiz activity presents statements to the user, who interacts with the application through buttons to select whether each statement is a life hack or a myth. This structure demonstrates the implementation of key Android development concepts such as activity lifecycle management, user interface design, and event handling.

Throughout the development process, several challenges were encountered and resolved. These included managing the correct linkage between XML layout components and Kotlin code, particularly ensuring that UI elements such as buttons were properly defined and referenced. Additional challenges involved organizing the project structure correctly for version control and ensuring that unnecessary files were excluded when preparing the project for upload to GitHub. Addressing these issues improved both the functionality of the application and the developer’s understanding of Android project management.

The project successfully meets its primary objectives by delivering a functional and interactive quiz application. However, there are opportunities for future improvement. These include implementing a scoring system to track user performance, enhancing the visual design for a more engaging user experience, adding a database to store questions and results, and expanding the range of quiz content. Overall, the LifeHackOrMyth application demonstrates foundational skills in mobile app development and provides a solid base for further enhancement and learning.
